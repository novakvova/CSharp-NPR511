# Специфікація: WorkingOperator

Навчальний проєкт (Lesson 6 — перевантаження операторів, C#/.NET). Консольний застосунок.

## 1. Структура проєкту

```
WorkingOperator/                 ← корінь рішення (тут CLAUDE.md, spec.md, README.md)
├── WorkingOperator.slnx         ← рішення, містить один проєкт
├── README.md                    ← нотатки з налаштування Claude Code
├── WorkingOperator/
│   ├── WorkingOperator.csproj   ← конфігурація проєкту
│   ├── Program.cs               ← точка входу (top-level statements)
│   └── Device.cs                ← клас Device (порожній)
├── bin/, obj/                   ← артефакти збірки (не редагувати)
└── .vs/                         ← службові файли Visual Studio
```

Батьківська папка `Lesson 6.Operator` і корінь git-репозиторію `Projects` містять інші уроки (`Lesson 1` … `Lesson 6`); вони не є частиною цієї специфікації.

## 2. Технології

| Параметр | Значення |
|---|---|
| Мова | C# |
| Платформа | .NET 9 (`net9.0`) |
| Тип проєкту | Console application (`OutputType=Exe`) |
| SDK | .NET SDK 10.0.403 (використаний для збірки; сумісний з `net9.0`) |
| Неявні using | увімкнено (`ImplicitUsings`) |
| Nullable-контексти | увімкнено (`Nullable`) |
| ОС розробки | Windows 11 |
| IDE | Visual Studio (`.vs/`, `.slnx`) |

## 3. Залежності

- **NuGet-пакети:** відсутні. У `WorkingOperator.csproj` немає жодного `PackageReference`.
- **Зовнішні сервіси, бази даних, мережа:** не використовуються.
- **Посилання на інші проєкти:** немає.
- **Системні залежності:** лише .NET 9 runtime (або SDK для збірки).

## 4. Архітектурні рішення

- **Один проєкт, одна збірка.** Архітектурних шарів немає; вся логіка має бути в одній збірці.
- **Точка входу — top-level statements** (`Program.cs`) без явного `Main`.
- **Кодування консолі — UTF-8** для вводу та виводу (`Console.InputEncoding`, `Console.OutputEncoding`), бо тексти виводяться українською.
- **Доменна модель:** клас `Device` (namespace `WorkingOperator`) — заготовка; передбачається реалізація на ньому перевантаження операторів.
- **Тестів немає** (ні тестового проєкту, ні тестових фреймворків).
- **Конфігурація** (appsettings, DI, логування) відсутня — проєкт не потребує.

## 5. Стан реалізації

| Компонент | Стан |
|---|---|
| `Program.cs` | Виводить заголовок «Перевантаження операторів», логіки немає |
| `Device.cs` | Порожній клас, без властивостей і операторів |
| Тести | Відсутні |

## 6. Команди

Запускати з папки, де лежить `WorkingOperator.slnx`:

- Збірка: `dotnet build WorkingOperator.slnx`
- Запуск: `dotnet run --project WorkingOperator/WorkingOperator.csproj`

Обидві команди перевірено: збірка успішна, 0 попереджень, 0 помилок.
